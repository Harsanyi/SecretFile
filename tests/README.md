# Validation

Run `test.ps1` from the repository root. It builds and runs both executables in Debug or Release without an additional test framework. Carrier tests initialize a hidden raylib window/audio device; the core test needs neither raylib nor a graphical context.

| Area | Cases |
| --- | --- |
| One-byte elements | All bit depths 1–8 |
| Two-byte elements | 1, 2, 7, 8, 9, 12, 16 bits |
| Four-byte elements | 1, 2, 8, 9, 16, 24, 31, 32 bits |
| Slot traversal | Independent bit-by-bit oracle, unchanged high bits, mixed-size reads/writes crossing elements, zero-depth byte slots |
| Capacity/bounds | Exact capacity, one byte too large, exhausted cursor, invalid/zero patterns, overflow, truncated container, impossible file count/filename length |
| Container | Multiple files, binary bytes, empty file, explicit little-endian count, absent marker |
| Images | PNG/JPG/JPEG input, lossless PNG export/reload at depths 1–8, exact-fit metadata accounting |
| WAV | Mono/stereo; 8/16/32-bit input fixtures normalized to 16-bit; export/reload at depths 1, 2, 7, 8, 9, 12, 16 |
| OBJ | Export/reload at depths 1, 2, 4, 8, 12, 16; float-buffer and payload equality, independent index/material copies, one-based faces with missing normals/UVs |
| UI/lifetime | Repeated model/audio previews including zero depth, unchanged source vertices, carrier-type switching, very short/silent waveform |
| Paths | Output beside carrier even after changing working directory; path stripping, invalid/reserved names, overwrite refusal, zero-depth Open/Save rejection |

Each carrier run creates a new directory under ignored `tests/output/`; `latest-run.txt` records its path. The fixtures are generated by the tests. The rendered UI screenshot uses the actual `SecFileUI` code and a generated image carrier, with two real payload entries. The selected capture is included in `docs/screenshot.png`.

The tests passed in Windows x64 Debug and Release with MSVC 14.50 and raylib 6.0. An additional MSVC AddressSanitizer run instrumented the project's integration code; the linked raylib library was not instrumented. This does not establish leak freedom or validate arbitrary external codecs/files.
